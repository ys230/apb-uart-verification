# APB3 UART 사양 (v0.2)

이 설계는 학습용 소규모 설계이며 16550 호환 주변장치가 아니다. 유일한 클록은 `PCLK`이고, `PRESETn`은 낮은 레벨에서 활성화된다. 생성 클록은 사용하지 않는다.

## APB 인터페이스

APB3 데이터 버스와 주소 버스는 모두 32비트다. 주소는 바이트 주소이며 4바이트 경계에 정렬되어야 한다. 전송은 설정 단계 한 사이클(`PSEL=1`, `PENABLE=0`)로 시작하고, 이후 접근 단계(`PSEL=1`, `PENABLE=1`)가 이어진다. 연속된 전송의 설정 단계 사이에 `PSEL`이 계속 높게 유지되더라도, `WAIT_CYCLES`는 전송마다 새로 적용된다. `PREADY`는 접근 단계 밖에서는 낮고, 설정된 수의 접근 대기 에지가 지난 뒤 높아진다. `PSLVERR`는 전송이 완료될 때만 의미가 있다.

모든 레지스터 부수 효과는 `PSEL && PENABLE && PREADY`가 참인 상승 에지에서 전송당 한 번만 발생한다. 잘못된 동작은 `PSLVERR`를 활성화하고, 읽기 데이터로 0을 반환하며, 상태를 바꾸지 않는다. 바이트 스트로브는 없다.

| 주소 | 레지스터 | 접근 | 리셋 값 | 의미 |
|---|---|---|---|---|
| `0x00` | CTRL | RW | 0 | 비트 0: TX 활성화, 비트 1: RX 활성화. 예약 비트는 읽을 때 0이며, 해당 비트에 대한 쓰기는 무시한다. |
| `0x04` | STATUS | RO | 상태에 따라 결정 | 비트 0: TX 가득 참, 1: TX 동작 중, 2: RX 비어 있음, 3: RX 가득 참, 4: RX 오버플로 sticky 비트, 5: RX 프레이밍 오류 sticky 비트. |
| `0x08` | SCRATCH | RW | 0 | 32비트 전체를 읽고 쓸 수 있는 레지스터. |
| `0x0c` | BAUD_DIV | RW | 16 | UART 비트당 `PCLK` 사이클 수. 허용 범위는 4~65535. TX 또는 RX 프레임이 진행 중일 때의 쓰기는 거부한다. |
| `0x10` | TXDATA | WO | — | 하위 바이트를 TX FIFO에 넣는다. FIFO가 가득 차 있으면 오류가 발생한다. |
| `0x14` | RXDATA | RO | — | 가장 오래된 RX 바이트를 하위 비트로 반환하고, 전송 완료 시 한 번 꺼낸다. FIFO가 비어 있으면 오류가 발생한다. |

매핑되지 않았거나 정렬되지 않은 주소, 읽기 전용 레지스터에 대한 쓰기, 쓰기 전용 레지스터에 대한 읽기, 허용 범위를 벗어난 분주 값, 사용할 수 없는 FIFO 접근은 모두 오류다. 읽기 오류가 발생하면 `PRDATA`는 0이다.

## FIFO 동작 규칙

TX와 RX FIFO는 기본적으로 각각 16바이트를 저장한다. 가득 참과 비어 있음 여부는 상승 에지 직전 상태를 기준으로 판단한다. 가득 찬 상태에서 넣기와 꺼내기가 동시에 발생하면 꺼내기만 수락하고, 빈 상태에서는 넣기만 수락한다. 그 사이의 점유량에서는 두 동작을 모두 수락하며 점유량은 유지된다. 비어 있지 않은 FIFO를 읽으면 가장 오래된 항목이 보이고, 수락된 꺼내기 에지 이후에 다음 항목으로 이동한다. 리셋하면 두 FIFO가 모두 비워진다.

## UART 동작 규칙

유휴 상태의 라인은 높은 레벨이다. 각 프레임은 낮은 시작 비트 1개, 최하위 비트부터 전송하는 데이터 비트 8개, 높은 정지 비트 1개로 구성된다. 각 비트는 `BAUD_DIV`개의 `PCLK` 상승 에지 동안 지속되며, 분주 값은 프레임마다 시작할 때 저장된다. TX 활성화 비트는 새 프레임의 시작을 제어한다. 진행 중인 프레임은 TX를 비활성화해도 끝까지 전송한다. 리셋하면 프레임을 중단하고 라인을 높은 레벨로 되돌린다.

비동기 RX 핀은 2단 플립플롭 동기화 회로를 거친다. 하강 에지가 후보 프레임을 시작한다. 수신기는 약 반 비트 뒤 낮은 시작 비트를 확인한 다음, 데이터 비트 8개와 정지 비트를 각 비트의 중앙에서 샘플링한다. 분주 값이 홀수이면 반 비트 간격은 내림한다. 거짓 시작 비트는 버린다. 정지 비트가 낮으면 해당 바이트를 버리고 프레이밍 오류 sticky 비트를 설정한다. 유효한 바이트가 들어올 때 RX FIFO가 가득 차 있으면 해당 바이트를 버리고 오버플로 sticky 비트를 설정한다. 기존 FIFO 내용은 유지된다. 두 sticky 비트는 리셋할 때만 지워진다. RX 비활성화 또는 리셋은 진행 중인 후보 프레임을 중단한다. 지원하는 최소 분주 값은 4다. 검증은 디지털 시뮬레이션으로 수행하며 아날로그 동작이나 메타안정성 검증 완료를 주장하지 않는다.

지정된 타이밍 검사는 DUT의 분주 값을 32로 설정하고, 독립적인 RX 소스가 비트당 각각 31사이클과 33사이클인 프레임을 하나씩 전송한다. 이는 디지털 시뮬레이션에서 측정한 특정 시험 지점이며, 모든 분주 값이나 입력 위상에 대한 일괄적인 허용 오차 보장은 아니다.

## 리셋과 범위

리셋은 APB 대기 및 진행 중인 UART 프레임을 취소하고 레지스터, FIFO, sticky 상태 비트를 초기화한다. IRQ, 패리티, DMA, AXI, 실제 FPGA 연동은 v0.2 범위에 포함되지 않는다.
