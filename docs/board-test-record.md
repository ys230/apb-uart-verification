# FPGA 실물 시험 기록 양식

**상태: 미실행.** 보드 정보와 실측 결과를 확인한 뒤 작성합니다. 분석용 HX8K 결과를 이 양식의 보드용 결과로 옮겨 적지 않습니다.

| 항목 | 실제 기록 |
|---|---|
| 보드 제조사 / 모델 / 리비전 | 미정 |
| FPGA part / 입력 클록 | 미정 |
| 공식 회로도 / 핀 제약 파일 근거 | 미정 |
| UART 어댑터 / I/O 전압 / 핀 연결 | 미정 |
| 리셋 연결 / 극성 / 동작 | 미정 |
| RTL commit 및 변경 여부 / 소스 해시 | 미실행 |
| 합성·구현 도구와 버전 | 미실행 |
| 클록 제약 / setup·hold / 제약 누락 / DRC | 미실행 |
| 프로그래밍 파일 SHA-256 / 다운로드 로그 | 미실행 |
| UART 검사 명령 / seed / byte 수 / JSON 경로 | 미실행 |
| 연결한 보드와 배선 기록 | 미실행 |
| 케이블 미연결 시험: timeout 검출 | 미실행 |
| 정상 연결 시험: 오류 0 / 전체 바이트 일치 | 미실행 |
| 리셋 / 전원 재인가 후 재시험 | 미실행 |
| 실패 원인 및 조치 / 아직 확인하지 않은 범위 | 미실행 |

저장 위치 예: `reports/runs/hardware/<보드명>/<실행일>/`. 원본 파일은 보관하고 공개 가능한 증거만 검토 후 별도 게시합니다.
